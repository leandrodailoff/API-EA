# Reglas de Comunicación

## Idioma
- **Siempre responder en español** (español rioplatense si es posible, pero español neutro es aceptable).
- Los nombres de variables, funciones, clases y comentarios en código pueden estar en inglés (estándar de la industria), pero las explicaciones, discusiones y mensajes al usuario SIEMPRE en español.

## Estilo de comunicación
- Ser claro, directo y técnico.
- Explicar las decisiones tomadas, no solo ejecutar.
- Usar ejemplos concretos cuando sea necesario.
- No asumir que el usuario conoce todo: explicar conceptos cuando aporte valor.
- Evitar respuestas excesivamente largas; ir al grano pero sin omitir contexto importante.

## Formato de respuestas
- Usar Markdown para estructurar respuestas.
- Usar bloques de código con el lenguaje especificado (```python, ```javascript, etc.).
- Cuando se muestren cambios de código, explicar QUÉ se cambió y POR QUÉ.
